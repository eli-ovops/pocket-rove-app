# Test checklist and evidence boundary

## Pure logic — compiled, execution pending Simulator infrastructure

- Same input seed yields the same plan.
- Display language is excluded from the selection seed.
- 04:59 and 05:00 fall into adjacent business-day keys.
- Completed canonical task IDs are excluded from selection.
- Egg decision is deterministic.
- Validator rejects duplicate, unapproved and release-incomplete task packs.
- 09:00 and 20:00 notification identifiers are stable.

## Requires a healthy Simulator

- SwiftData save/relaunch recovery, completion/revoke history visibility, and same-day plan immutability.
- Onboarding ID, Today completion, History appearance/disappearance after revoke, language and music/sound preference persistence.
- Notification prompt state presentation and schedule/cancel/re-schedule identifier behavior.

## Requires a real device

- Notification authorization behavior, delivery, tap routing and system settings recovery.
- DST/time-zone transition behavior and external clock manipulation.

## Not a release assertion

The small safe debug pack only validates mechanics. It does not validate the 166-core/56-egg source pack, release English, safety review or licences.
